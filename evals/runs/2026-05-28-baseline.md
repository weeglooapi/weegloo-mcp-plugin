## Summary

- **What worked:**
  - P1 (service architecture), P3 (mixed-field ContentType), P4 (delivery token), P7 (media debug) all hit 3/3 ceiling.
  - Security-critical anti-patterns (Administrator on token, PAT in client, raw HTTP) had **zero hits across 24 runs**. Strong baseline on the highest-stakes guardrails.
  - Whenever a weegloo skill *did* trigger, content was applied accurately — skill bodies are correct; the gap is trigger reliability.
  - The `weegloo-media-lifecycle` ambient rule (no companion skill) produced perfect output in all 3 runs — demonstrates that well-written reference-style rules don't always need a skill.

- **What broke:**
  - **P2 R2 LongText trap**: agent invoked the skill, cited its rule about LongText, then defaulted to LongText anyway. Skill body needs an unambiguous "default to RichText" lead sentence.
  - **P5 R3 + P6 R1/R3 + P8 R3**: weegloo skill not invoked despite being the correct guide. The ambient rule covered the result. Removing the rule (as original Plan C proposed) would convert these to real failures.
  - **`superpowers:brainstorming` noise**: triggers on "build me X" prompts and blocks downstream weegloo skill invocation. P8 R3 never recovered to a weegloo skill.

- **Surprises:**
  - Strongly bimodal results on P2 (R1/R3 ceiling, R2 trap fired) → low variance on most prompts but real bimodality on the central modeling anti-pattern.
  - Rule-only domain (P7 media-lifecycle) outperformed skill-existing domains (P6 default-locale) — skill existence ≠ better performance.
  - P5 R3 stayed MCP-only under PAT-expiry pressure (R1) — discipline survived failure scenario.

- **Followups to consider:**
  - **First intervention to measure (#3 in earlier plan):** rewrite all 13 skill descriptions with "trap detector" pattern (start "Use before…", include user phrases like "blog", "members board", "다국어", failure modes, object names). Measure delta against this T0.
  - **Second intervention:** strengthen weegloo-create-content-type **skill body** to lead with "Default to RichText. Pick LongText only if user explicitly confirms full-text search." Target: P2 R2-class failures → 0.
  - **Do NOT execute original Plan C step 2 (rule DELETE) before above two interventions plus re-measurement.** Risk of regression in P5/P6/P8 is now empirically established.
  - **Rubric v2:** switch to mean-floor for D1-D4 to surface partial failures masked by median. Retroactively recompute T0.
  - **Add P9** (long-term): collision handling for repeated WebHosting subdomain (would have caught a real flow not tested by P5).
